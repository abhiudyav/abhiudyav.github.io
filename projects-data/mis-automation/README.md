# MIS Automation (Python)

## Overview
Python-based MIS automation pipeline that converts raw CSV/XLSX data into a structured MIS report package.

## Problem Statement
Manual recurring MIS preparation is repetitive and can be inconsistent across runs.

## Solution
A modular pipeline that profiles, cleans, transforms, analyzes, and exports reporting outputs with optional AI and SQL layers.

## Features
- Data profiling and cleaning with audit logs
- KPI and pivot/report generation
- Optional AI insight generation and SQL analysis
- Power BI-ready export outputs

## Technologies Used
Python, pandas, openpyxl, xlsxwriter, SQLAlchemy/SQLite, Streamlit, pytest.

## Workflow
1. Ingest source file (CSV/XLSX)
2. Profile and clean data
3. Compute KPIs and reporting artifacts
4. Export MIS Excel report and related outputs
