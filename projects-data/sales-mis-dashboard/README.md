# Sales MIS Dashboard

## Overview
Formula-driven Excel MIS dashboard using Australian retail order data with interactive filters, KPI cards, charts, rankings, and data quality checks.

## Problem Statement
Managers need filterable sales performance reporting without rebuilding pivots each time.

## Solution
A single Excel workbook with a dashboard sheet powered by formula-based calculation logic.

## Features
- Seven filters (year, quarter, month, category, region, segment, salesperson)
- KPI cards and chart visuals
- Top-performer tables and insights panel
- Data quality checks for duplicates and missing/invalid values

## Technologies Used
Microsoft Excel, formulas (including INDEX/MATCH and SUMPRODUCT), Data Validation, native charts.

## Workflow
1. Load the workbook
2. Choose filters
3. Review KPIs/charts/rankings
4. Use insights and quality panel for reporting checks
