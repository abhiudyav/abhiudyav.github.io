Sales MIS Dashboard

A fully interactive, formula-driven Excel dashboard over 1,039 Australian retail order lines — seven live filters, 8 KPI cards, 6 native charts, top-performer rankings and an auto-generated insights panel, with no PivotTables, slicers or VBA.

  • SUMPRODUCT + INDEX/MATCH calculation engine, not PivotTables
  • 7 cascading filters via Data Validation dropdowns
  • Built-in data quality panel (duplicate orders, missing/negative values)

Completed

MIS Automation (Python)

A modular Python pipeline that takes a raw CSV/XLSX and produces a full MIS Excel report: profiling, cleaning with a full audit log, KPIs, pivots with native charts, optional Claude-generated insights, read-only SQL analysis, and a Power BI-ready export.

  • 9-phase pipeline, 44 automated tests, independent quality-control pass
  • AI insight layer never computes numbers — only interprets pre-computed KPIs
  • Streamlit UI and CLI share one pipeline so they can't diverge

Built — self-learning project

AI-Powered MIS Executive Automation (n8n)

An email-to-Excel workflow: monitors Gmail for Excel/CSV attachments, has the Claude API read the actual workbook plus the email instructions, then either processes the file via Python/FastAPI and emails it back or asks a clarifying question.

  • Confidence-based decision layer: low-confidence requests get a clarification email, not an unsupervised edit
  • Job ID, output filename and row counts tracked per run
  • Error handling and retry logic across API and processing steps
