AI-Powered MIS Executive Automation

Built — self-learning project n8nPython/FastAPIGmailClaude APIREST APIJSONExcel Automation

An email-to-Excel workflow: someone emails a spreadsheet plus an instruction, the workflow works out what is being asked, does it when it is confident, asks a clarifying question when it is not, and emails the finished workbook back.

ℹ Source of this write-up: the description below comes from my resume. The n8n workflow export, screenshots and sample runs have not been added to this repository yet, so node-by-node detail and output screenshots are intentionally not shown. They will be added here once the workflow JSON (with credentials removed) is committed.

01Overview

The workflow monitors Gmail for incoming emails that carry Excel or CSV attachments, validates them, and extracts both the attachment and the email text. A Python/FastAPI service inspects the workbook structure so the Claude API can reason over the real spreadsheet content together with the sender's instructions, rather than the instructions alone.

02Business Problem

Routine spreadsheet requests arrive by email — edit this column, filter that data, add a summary — and each one is handled by hand: open the file, work out what is wanted, make the change, reply. It is repetitive, and an unclear request handled without asking leads to wrong edits.

03Solution

Automate the whole loop, but keep a safety valve: the AI returns a structured decision with a confidence score. Clear requests are carried out automatically; low-confidence requests trigger a clarification email instead of an unsupervised edit.

04Workflow Architecture

Stages are taken from the resume description. This diagram shows the logical flow, not individual n8n node names.

Gmail: email with Excel/CSV attachment→ Validate + extract attachment & email text→ FastAPI: inspect workbook structure
Claude API: structured decision + confidence→ Confidence check
Low confidence → clarification email to sender
Clear request → FastAPI Excel processing→ Job ID, output filename, row counts tracked→ Completed workbook emailed back

05Automation Flow

  • Intake: Gmail is monitored for emails with Excel/CSV attachments; attachments and email content are validated and extracted.
  • Inspection: a Python/FastAPI service reads the workbook structure.
  • Decision: the Claude API analyses the actual sheet content with the email instructions.
  • Branch: low confidence sends a clarification email; a clear request goes to processing.
  • Processing and delivery: FastAPI carries out the operations, tracking job ID, output filename and row counts, and the finished workbook is emailed to the requester.
  • Reliability: error handling and retry logic across the API and processing steps.

06n8n Nodes

The exact node list will be published with the workflow export. From the resume, the workflow involves Gmail email handling and calls to the FastAPI service and the Claude API over REST with JSON payloads.

07AI Integration

The Claude API receives the workbook structure and content plus the email instructions and returns a structured JSON response with: decision, confidence score, task, reason, required columns and requested operations. That response drives the branch between "clarify" and "process". The AI decides; the Excel changes themselves are carried out by the FastAPI processing pipeline.

08Data Processing

Excel/CSV workbooks are inspected and processed by a Python/FastAPI service, which reports job ID, output filename and row counts for each run.

09MIS Reporting

It supports MIS work by turning emailed spreadsheet requests into processed workbooks without manual handling, with a clear trail per job.

10Output

A completed Excel workbook emailed back to the requester, or a clarification email when the request is unclear. Sample outputs and screenshots to be added.

12Business Value

  • Reduces repetitive handling of emailed spreadsheet requests.
  • Avoids unsupervised edits on unclear requests via the confidence check.
  • Standardised processing and a per-job record.

No percentage improvements are claimed; these are design benefits, not measured results.
