## Projects

### [Sales MIS Dashboard](projects/sales-mis-dashboard.html)
A fully formula-driven Excel dashboard over 1,039 Australian retail order
lines — 7 live filters, 8 KPI cards, 6 native charts, ranking tables and an
auto-generated insights panel. No PivotTables, Slicers or VBA — see the case
study for why. **Status: completed.**

### [MIS Automation (Python)](projects/mis-automation.html)
A 9-phase, 44-test Python pipeline that turns a raw CSV/XLSX into a fully
audited MIS Excel report: cleaning log, KPIs, pivots with native charts,
optional Claude-generated insights, read-only SQL analysis, and a Power
BI-ready export. **Status: completed.**

### [AI-Powered MIS Executive Automation (n8n)](projects/n8n-mis-automation.html)
Email-to-Excel workflow using n8n, Python/FastAPI, Gmail and the Claude API, with
a confidence-based decision layer (clarification email vs. automatic processing).
**Status: built as a self-learning project; workflow export and screenshots still
to be added to this repo.**

### Smaller practice projects
Power BI sales dashboard, Excel personal expense tracker, MySQL sales/customer queries.
